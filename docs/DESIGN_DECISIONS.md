# Engineering decisions and tradeoffs

1. **Python FastAPI monolith + PostgreSQL:** a single modular backend is easier to test, deploy and reason about than fragmented analysis microservices. SQLAlchemy models and Alembic migrations provide schema evolution. SQLite exists only for isolated smoke/unit tests.
2. **Collector rather than Kafka:** the target lab workload is modest, so a Collector memory limiter, batch processor and bounded exporter retries suffice for demonstrations. The absence of durable queued replay is an explicitly documented reliability limitation; Kafka would be justified only after real loss/recovery requirements and throughput measurements.
3. **Direct span-parent topology:** observed inter-service parent relationships provide an inspectable provenance and can be rebuilt on out-of-order arrival. They miss dependencies when traces are sampled or context propagation breaks.
4. **Rolling median/MAD + Isolation Forest:** robust baselines and a real fitted comparator are more defensible than an unevaluated neural network. A GNN has not demonstrated an improvement and is deliberately excluded.
5. **Deterministic graph-temporal ranking:** the algorithm is inspectable, supports ablation, shows contradictions and avoids false causal certainty. Scores are uncalibrated, and no supported claim of causal identification is made.
6. **One multi-role lab service image:** actual independent HTTP processes provide a real distributed call graph without ten different copies of essentially identical boilerplate. Isolated Postgres and Redis back the database and cache endpoints.
7. **Bounded lab, no arbitrary target:** fixed service names, loopback published ports, TTL, 2 worker slots and small rates limit accidental disruption. The lab intentionally does not support externally supplied hosts or packet injection across arbitrary networks.
8. **React/TypeScript and SVG diagrams:** a first-party accessible semantic UI with dependency graph and line chart implemented without a heavy visualization bundle; this does not claim formal WCAG accreditation. CI's frontend build and browser test are required release gates but not verified in the current offline environment.
